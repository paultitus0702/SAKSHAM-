# Netlib LP Benchmark Repository

This directory is designated for authentic Netlib LP benchmark instances (such as `afiro.mps`, `adlittle.mps`).

Per SAKSHAM design principles:
- Fake benchmark files or synthetic files mislabeled as Netlib are strictly prohibited.
- Authentic MPS files will be downloaded or placed here during Phase 11 for LP parser fidelity and solver integration validation.
